# 看见孩子的八种聪明 · 多元智能家庭评价与培养方案

一份给 6–12 岁孩子家庭用的**多元智能（Multiple Intelligences）评价与培养手册**，单页应用，打开即用。

在线访问：<https://gamewalker5840.github.io/parenting-mi/>

## 这份方案解决什么问题

很多"多元智能测评"只给一串分数，家长看完还是不知道该做什么。这份方案把评价做成一条可执行的闭环：

1. **填**：64 题儿童版调查表（把 Armstrong 成人版量表改写为孩子日常可观察的行为，统计结构与原表 100% 兼容）
2. **统**：勾选数 → 八项圈数（第 n 题归属第 ((n−1) mod 8)+1 列）
3. **画**：八环饼图（第 k 环以内 = k 分）+ 雷达图，实时生成，与纸上手工填涂结果一致
4. **读**：五档分档、解读三原则、常见优势组合、五类误差与使用边界
5. **扬长**：八项优势各自的 3 个放大动作
6. **补短**：不做硬补，用"绕道补"的四个原则与八项具体做法
7. **落地**：家庭环境布置、亲子话术对照、"1+1+1"一周节奏、十个最容易踩的坑
8. **复评**：90 天行动方案与复评记录表

页面底部还有**一键导出**：把作答数据 + 完整方案生成一份可离线阅读、可打印的 HTML 指导手册。

## 隐私

- **不上传任何数据**：页面没有后端、没有统计脚本、没有第三方字体/CDN 请求。
- 作答草稿只保存在你**本机浏览器**的 localStorage 里，可一键清除。
- 导出的手册是在本地浏览器里生成的 HTML 文件，不经过服务器。

## 技术说明

- 单文件自包含：中断网络也能完整使用（适合打印、发给家人、拷进平板）。
- 图表全部为**手写 SVG**（八环饼图 + 雷达图），不依赖任何图表库。
- 响应式：桌面为左侧章节栏，≤1080px 转为固定顶栏 + 可呼出的目录抽屉。
- 无障碍：原生 `checkbox` + `label` 关联、`aria-live` 计数播报、skip-link、图表 `role="img"` 描述。
- 打印样式：`@media print` 已针对 A4 排版优化，可直接 Ctrl/⌘+P 输出纸质材料。
